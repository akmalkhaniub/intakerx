# 🏥 IntakeRx — Clinical Safety & AI Guardrail Protocol

This protocol documents the safety boundaries, input sanitization rules, and clinical liability safeguards enforced by IntakeRx.

---

## 1. Dual-Layer Guardrail Architecture

```
Patient Input
     │
     ▼
[Layer 1: Input Guardrail]
  ├── Regex Jailbreak Filter (e.g., "Ignore previous instructions", "System prompt")
  ├── PII Redaction Engine (Masks SSN, MRN, direct phone numbers)
  └── Semantic Medical Intent Classifier (Rejects non-triage prompts)
     │
     ▼
[Clinical RAG Engine] (PostgreSQL + pgvector Triage Guidelines)
     │
     ▼
[Layer 2: Output Guardrail]
  ├── Anti-Diagnostic Filter (Blocks "You have disease X", "I diagnose you with...")
  ├── Anti-Prescription Filter (Blocks dosage recommendations or medication advice)
  └── Emergency Redirection Trigger (Auto-prompts "Call 911 / Go to nearest ER")
     │
     ▼
Structured FHIR-Compliant SOAP Note
```

---

## 2. Mandatory Physician Sign-Off (Human-In-The-Loop)
- No clinical note generated by IntakeRx is transmitted to Electronic Health Records (EHR) without an authenticated clinician reviewing, editing, and signing off via the Clinician Portal (`/clinician`).
